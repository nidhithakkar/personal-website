# nidhithakkar.com

Personal portfolio for Nidhi Thakkar — builder & engineer.

## Stack

- Next.js (App Router) + TypeScript + Tailwind CSS
- Framer Motion
- Resend (contact form)

## Develop

```bash
npm install
cp .env.example .env.local
# add RESEND_API_KEY and CONTACT_TO_EMAIL
npm run dev
```
